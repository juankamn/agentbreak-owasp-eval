# Créditos y procedencia

El proyecto original **AgentBreak** fue creado por **Christian Urcuqui** y sus
colaboradores. Su repositorio es:

<https://github.com/urcuqui/AgentBreak>

Esta réplica académica utiliza la versión `0.2.0`, commit
[`9effe7b6317a4e90b18ab895c06a2a47f8cb91c1`](https://github.com/urcuqui/AgentBreak/commit/9effe7b6317a4e90b18ab895c06a2a47f8cb91c1).
El historial original se conserva para mantener la autoría y la trazabilidad.

Los laboratorios OWASP y Agent Trust, sus escenarios, código, datos
sintéticos, controles y pruebas originales proceden de AgentBreak. La
licencia declarada por el proyecto original es MIT, según `pyproject.toml`;
se conserva esa declaración y la atribución original del paquete.

El repositorio del equipo es:

<https://github.com/juankamn/agentbreak-owasp-eval>

En su primera versión, el trabajo de **Jairo Andrés Valencia, Juan Camilo
Macías y Ulises Caicedo** consiste en reproducir el funcionamiento original,
documentar la instalación y ejecución, conservar evidencias verificadas y
organizar el entorno de desarrollo. No se atribuye al equipo la creación de
los laboratorios originales. Las extensiones futuras deberán distinguirse
de esta línea base y documentar sus cambios.

## Exploración de Jairo

La rama `experiment/jairo-agent-security-ctf` identifica la experimentación
personal de **Jairo Andrés Valencia** para preparar un laboratorio CTF de
agentes de IA. Su README en español y el catálogo inicial describen una
evolución propuesta; esta preparación todavía conserva el código ejecutable
de AgentBreak sin cambios.

La atribución a Christian Urcuqui y al repositorio original se mantiene en
esta rama. Las contribuciones nuevas se distinguen mediante la documentación
y el historial de cambios, sin atribuir al equipo la autoría del proyecto
original.
